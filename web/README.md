# 跨平台网页

本目录只保存由 NeuroBridge 网关 HTTP 服务托管的 HTML/CSS/JavaScript 资源，不包含串口、蓝牙、算法或系统进程控制逻辑。

- `capture/`：耳机实时原始数据查看页。由网关发布到 `http://127.0.0.1:8080/capture/`，通过现有 WebSocket 契约订阅 `eeg.raw`、`hr.raw` 和 `status`；可在 16 进制与 10 进制间切换，逐字节空格分隔并用 `|` 区分序列号、六路 EEG 数据点和心率，同时显示页面推算丢包率。页面可导出本机诊断日志，但会隐藏完整原始字节和 Base64，只保留网关状态、计数、序列异常、丢包和脱敏协议记录。
- `b-client-test/`：本机可视化与兼容 B 端 WebSocket 联调页。默认由网关的回环 HTTP 服务发布到 `http://127.0.0.1:8080/`，并动态注入 WebSocket 地址；旧有线策略仍可复用同一页面。

两个页面都无构建步骤，但运行时只能依赖当前网关提供的 HTTP 页面和 WebSocket 服务。两者都不能直接访问蓝牙、串口、USB 或算法进程，因此不会抢占网关正在使用的串口。`capture/` 的“开始/停止”对应当前 WebSocket 连接的 `subscribe`/`unsubscribe`，只控制页面数据推送，不停止网关进程或设备连接。
