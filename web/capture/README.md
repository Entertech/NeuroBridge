# 静态头环采集控制台

将 `neurobridge-static-console.zip` 完整解压，双击 `capture/index.html`。默认连接网关 `http://192.168.88.10:8766`；浏览器所在电脑无需 Python、算法 SDK 或蓝牙驱动。扫描、设备连接、采集、算法和录制都在 Ubuntu 网关运行。

1. 先让电脑的有线网卡与网关处于同一专用网段。Windows 可双击同包的 `b-client-test/configure-wired-ip.bat`，追加默认 B 端地址 `192.168.88.20/24`。
2. 更新并启动网关。部署配置需启用 `[download].enabled`、`capture_control_enabled`；真实设备接入验证通过后启用 `[ble].enabled`。未启用 BLE 时页面仍可查看状态，开始扫描返回明确错误。
3. 打开页面后自动读取状态和日志，不在浏览器本机扫描设备。网关按部署配置自动运行设备任务；停止后可用“开始扫描”恢复。“停止采集”只停止设备任务和结束录制，HTTP/WS 服务继续运行。
4. “停止并保存 ZIP”先停止当前采集，确认会话完成后下载原始 EEG、心率、独立算法结果和清单。已完成会话直接“保存 ZIP”；没有会话时禁用保存，活动会话不能直接导出。
5. “打开 B 端订阅页”打开同包工具并携带实际 WS 地址；B 端仍按需订阅，控制台不自动创建波形订阅。

默认 HTTP 地址为 `http://192.168.88.10:8766`，WS 地址从网关状态读取。现场改过地址、端口时，在输入框填写实际 HTTP 根地址后点击连接；不要填 WS 地址或 `/downloads` 路径。该地址不依赖浏览器电脑的 `127.0.0.1`。通过 macOS 本地 POC 或网关 HTTP 托管打开时，自动使用页面同源地址，兼容已有本地 POC 接口。

浏览器可能询问是否允许访问本地网络，请允许当前可信页面访问部署网关。若 `file://` 访问仍被策略阻止，可直接打开同一套静态文件的网关托管入口：[默认采集控制台](http://192.168.88.10:8766/capture/index.html)。无需关闭浏览器安全功能。Chrome 的限制见 [本地网络访问说明](https://developer.chrome.com/docs/modern-web-guidance/guides/security/local-network-access)。

页面每 1500 ms 查询状态和日志，单次只运行一组轮询，操作期间暂停轮询，丢弃已切换地址或操作前的迟到响应。开始/停止失败不会自动重复执行；错误显示在页面，可对照网关日志。断开或关闭页面不会停止网关采集。界面日志是有界摘要（最多 200 条、每条 2048 字符），不替代持久化日志；原始字节和连续波形不展示在诊断区。

“停止采集”结束设备任务，不会修改部署中的录播允许策略；停止后若允许录播且有可用历史会话，B 端取数仍可能收到录播数据。需要禁止录播时，由网关运维在网关本机使用 `sudo /opt/neurobridge/venv/bin/python -I -m neurobridge.replay_control disable`；恢复允许用 `enable`，查询用 `status`。禁止操作生效后 `mode` 切回 `live`，未连接头环时表示等待实时设备。开关会重启运行中的服务，B 端须重连和重新订阅，区别于页面“停止采集”保留 HTTP/WS 监听。页面没有录播开关按钮，关闭网页也不修改该策略。

网关持久化日志由服务自动记录，页面日志只是内存摘要，无需另外运行“开启日志”脚本。需要约三天诊断包时，在网关终端执行 `sudo /opt/neurobridge/linux/collect-runtime-diagnostics.sh --since '72 hours ago' --output-dir /tmp`；该脚本只导出已有日志，不保证系统保留了完整三天。B 端异常消息与场景表位于源码 `doc/tech/B端异常消息与场景排查表.md`。

此页面属于现场运维工具，仅供已授权人员在专用有线或受控现场网络使用。接口不添加 TLS/Token；来源检查用于浏览器访问控制，不是用户身份认证。不得暴露至公网或不受控网络。接口定义与配置项见源码仓库 `doc/tech/网关 SSH 运维与 B 端录播联调指南.md`。

静态客户端无需本机服务，但完整功能要求网关更新到支持采集控制 API 的版本。源码/模拟回归通过不代表真实头环、算法结果或现场验收通过。
