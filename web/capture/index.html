USB 串口状态依次为：未连接 → 连接中 → 已连接（找到固定握手）→ 校验中（回写握手 ACK 并等待 01；完整重复握手会重新 ACK）→ 校验成功（算法就绪且无响应 E1 已写入）。整个窗口未返回独立 01、算法未就绪或 E1 写入失败会进入校验失败；只有校验成功后网关才接收和转发实时数据。

“窗口”表示网关聚合数据的本地时间范围，默认时长 600ms，不是设备序列号。页面丢包率 = 累计缺失 EEG 包数 ÷ 从首包到最高序列号的累计应收包数；支持 65535 → 0 回绕，重复包不增加已收包数，统计窗口内的乱序补包会减少缺失数。

运行边界

页面资源和 WebSocket 都由本机网关提供，只访问配置好的网关地址；不直接访问串口，不上传数据，不使用 CDN、遥测或浏览器持久化存储。原始数据导出只包含时间戳和页面实际收到的字节；诊断日志仍会隐藏完整 EEG/心率原始数据及 Base64，只保留状态、计数和异常信息。
