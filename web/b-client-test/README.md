# 本机可视化与兼容 B 端联调网页

该页面复用版本台账登记的 WebSocket 契约。当前默认场景由同一台银河麒麟网关主机加载页面；兼容 `wired_b_side` 策略时，也可供独立 B 端联调。

生产/现场运行先启动 NeuroBridge，然后在同机浏览器访问：

```text
http://127.0.0.1:8080/
```

网关会动态注入 `ws://127.0.0.1:8765/neurobridge/v1/ws`。页面使用 `neurobridge.v1` 子协议，可测试 `getStatus`、`getLatest`、`subscribe` 和 `unsubscribe`，且不会发送 Ping/Pong 或 JSON 心跳。

本机页自动读取网关配置中的设备来源，建连后先查询并订阅设备状态。独立联调页填写一个网关 WebSocket 地址，连接后通过 `getStatus` 识别网关提供的设备来源。点击「断开」会结束该网关连接，并清空该连接提供的读数。

连接 Windows 双设备网关时，两路数据都走这一条 WebSocket 连接。页面根据 `data.source` 更新对应的设备栏，每栏的协议请求自动填写 `params.source`，分别管理两路订阅。连接关闭时两路订阅同时失效。

Windows 本机联调页根据设备状态显示对应的实时数据、图表、协议请求与日志。设备接入后自动显示，断开后收起。页面自动订阅设备状态。

「协议请求」按设备提供状态查询、最新值查询、订阅、取消订阅和自定义 JSON。每栏分别保留流选择和订阅列表。本机页显示当前网关配置的设备请求栏。

「实时算法数据」左栏显示耳机串口，右栏显示头环蓝牙。两路指标和图表直接并排，窄屏时按耳机、头环的顺序上下排列。每路概览显示放松度、压力值、心率、HRV、注意力、Flow、和谐度和激活度，后面是脑波波形和频段能量。首次收到相应流的有效窗口但缺少该读数时，页面提示「本窗口未上报」。连续订阅会更新对应指标和图表，`getLatest` 可读取一次。指标按算法原值显示，心率单位为 bpm。

注意力、放松度、愉悦度、压力、和谐度、激活度和 Flow 使用 SDK 的 0–100 分标尺。和谐度卡片用 50 作参考线，突出显示当前分数所在的一侧。SDK 报表依据平滑后的曲线统计和谐区间。Flow 卡片用 SDK 的 100/3 和 200/3 分界突出显示低分、中间或高分区。低分区对应丢失提示的分数条件，高分区对应恢复提示的分数条件。实际触发结果由 SDK 随 `flow.meditationTips` 上报，可在窗口详情查看。缺失、无效、沿用或零值窗口的分段区域保持未选中。双设备 EEG 校准后的显示值可能越过标尺，页面仍显示网关原值。

心率用 bpm，HRV 用 ms，频段能量用 dB。成人静息心率参考 60–100 bpm。 [American Heart Association](https://www.heart.org/en/healthy-living/exercise-and-physical-activity/fitness-basics/target-heart-rates)

窗口详情同时显示脑电质量和心流提示的已定义代码含义。睡眠状态和分期在 `sleep.updated=true` 的窗口标注状态名称，睡眠指标默认折叠。

连续订阅保持 `as_available` 事件接收方式。每 600 ms 分别刷新每台设备的 EEG 算法、HR 算法、原始 EEG 和原始 HR 最新窗口。同一订阅内分开发送的数据可以在同一轮刷新中显示。脑波波形每个窗口到达即追加并重绘，无效窗口插入断点并保留有效样本。窗口模式订阅和录播事件按原节奏显示。

脑波图按设备和通道分别保留最近 500 个样本。连续订阅时，新样本从右侧进入，旧样本向左滚动。同一窗口重复到达时只追加一次。设备断开或切换采集会话后，波形从新数据开始绘制。

「实时窗口详情」默认展开，显示各算法流的时间和有效性，以及脑电质量、各频段能量、愉悦度、冥想提示、和谐度和激活度等指标。脑电算法详情中的「睡眠指标」默认折叠，展开可查看五项睡眠数据。设备详情同步显示信号质量、算法状态和网关报告的脑电指标来源。订阅 `hr.raw` 后，可展开「原始心率窗口」查看时段、单包字节数和 Base64。勾选「同时接收无效窗口」可查看网关发送的原因。波形横轴为样本序号，纵轴显示算法幅度原值。频段图使用能量原值绘制刻度，缺失值以 `—` 表示。

「协议日志」左栏为耳机串口，右栏为头环蓝牙。每栏可独立复制或清空，最多保留最近 200 条。新版报文在 `data.source` 中标注 `headset`（耳机）或 `headband`（头环）。页面只用已确认设备来源的报文更新算法读数。

每栏默认开启「跟随最新」。向上滚动查看历史时，该栏会暂停跟随，新日志继续追加。点击「跟随最新」回到底部并恢复跟随。

通过隔离专网独立联调时，打开 `index.html`，输入批准的网关 WebSocket 地址。生产回环网关校验固定 Origin，应通过网关提供的本机 HTTP 页面访问。
