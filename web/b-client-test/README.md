# 本机可视化与兼容 B 端联调网页

该页面复用版本台账登记的 WebSocket 契约。当前默认场景由同一台银河麒麟网关主机加载页面；兼容 `wired_b_side` 策略时，也可供独立 B 端联调。

生产/现场运行先启动 NeuroBridge，然后在同机浏览器访问：

```text
http://127.0.0.1:8080/
```

网关会动态注入 `ws://127.0.0.1:8765/neurobridge/v1/ws`。页面使用 `neurobridge.v1` 子协议，可测试 `getStatus`、`getLatest`、`subscribe` 和 `unsubscribe`，且不会发送 Ping/Pong 或 JSON 心跳。

本机页自动读取网关配置中的设备来源，建连后先查询并订阅设备状态。数据进入「耳机串口」或「头环蓝牙」区，实时／录播显示在「采集模式」中。手动订阅的 EEG、心率、HRV 和原始字节统计显示在当前连接对应的区域。

打开页面即可看到放松度、压力值、心率、HRV、注意力和 Flow 指标卡，以及下方的脑波波形和频段能量图。连续订阅会更新对应指标和图表，`getLatest` 可读取一次。每张卡显示自己的时间，标题标记当前设备及实时或录播模式。指标按算法原值显示，心率单位为 bpm。

在当前设备区展开「实时窗口详情」可查看各算法流最近一次实时窗口的时间、有效性及指标。勾选「同时接收无效窗口」可查看网关发送的原因。波形横轴为样本序号，纵轴显示算法幅度原值。频段图使用能量原值绘制刻度，缺失值以 `—` 表示。

通过隔离专网独立联调时，打开 `index.html`，输入批准的 WebSocket 地址，并按该网关的实际配置选择来源后连接。来源选择只影响页面展示，未选时数据进入「来源未指定」区。生产回环网关校验固定 Origin，应通过网关提供的本机 HTTP 页面访问。
