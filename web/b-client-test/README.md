# 本机可视化与兼容 B 端联调网页

该页面复用版本台账登记的 WebSocket 契约。当前默认场景由同一台银河麒麟网关主机加载页面；兼容 `wired_b_side` 策略时，也可供独立 B 端联调。

生产/现场运行先启动 NeuroBridge，然后在同机浏览器访问：

```text
http://127.0.0.1:8080/
```

网关会动态注入 `ws://127.0.0.1:8765/neurobridge/v1/ws`。页面使用 `neurobridge.v1` 子协议，可测试 `getStatus`、`getLatest`、`subscribe` 和 `unsubscribe`，且不会发送 Ping/Pong 或 JSON 心跳。

本机页自动读取网关配置中的设备来源，建连后先查询并订阅该设备状态。独立联调页可分别选择耳机串口和头环蓝牙，为两路填入各自的 WebSocket 地址并连接。协议请求、订阅和断开操作应用于当前选择的来源。断开一路后清空该路读数。

「实时算法数据」为放松度、压力值、心率、HRV、注意力和 Flow 各显示一张卡。每张卡内同时显示耳机串口和头环蓝牙的读数与各自的时间。「图表窗口」可同时显示耳机与头环的窗口，也可单独查看一路。每个来源的窗口包含自己的脑波波形和频段能量。连续订阅会更新对应指标和图表，`getLatest` 可读取一次。指标按算法原值显示，心率单位为 bpm。

展开「实时窗口详情」可查看各算法流最近一次实时窗口的时间、有效性及指标。勾选「同时接收无效窗口」可查看网关发送的原因。波形横轴为样本序号，纵轴显示算法幅度原值。频段图使用能量原值绘制刻度，缺失值以 `—` 表示。

通过隔离专网独立联调时，打开 `index.html`，输入批准的 WebSocket 地址，并按该网关的实际配置选择来源后连接。来源选择用于页面标注，未选时显示「来源未指定」。生产回环网关校验固定 Origin，应通过网关提供的本机 HTTP 页面访问。
