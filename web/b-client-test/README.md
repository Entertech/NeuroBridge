# 本机可视化与兼容 B 端联调网页

该页面复用版本台账登记的 WebSocket 契约。当前默认场景由同一台银河麒麟网关主机加载页面；兼容 `wired_b_side` 策略时，也可供独立 B 端联调。

生产/现场运行先启动 NeuroBridge，然后在同机浏览器访问：

```text
http://127.0.0.1:8080/
```

网关会动态注入 `ws://127.0.0.1:8765/neurobridge/v1/ws`。页面使用 `neurobridge.v1` 子协议，可测试 `getStatus`、`getLatest`、`subscribe` 和 `unsubscribe`，且不会发送 Ping/Pong 或 JSON 心跳。

本机页自动读取网关配置中的设备来源，建连后先查询并订阅该设备状态。独立联调页有耳机串口和头环蓝牙两个连接入口，可分别填入 WebSocket 地址并连接。每个连接行的「断开」只断开该路并清空该路读数。

Windows 双设备本机页使用一条 WebSocket 连接接收两路数据，并根据 `data.source` 更新设备栏。每栏的协议请求自动填写 `params.source`，分别管理两路订阅。连接关闭时两路订阅同时失效。

Windows 本机联调页根据设备状态显示对应的实时数据、图表、协议请求与日志。设备接入后自动显示，断开后收起。页面自动订阅设备状态。

「协议请求」按设备提供状态查询、最新值查询、订阅、取消订阅和自定义 JSON。每栏操作对应的连接，分别保留流选择和订阅列表。本机页显示当前网关配置的设备请求栏。

「实时算法数据」左栏显示耳机串口，右栏显示头环蓝牙。两路指标和图表直接并排，窄屏时按耳机、头环的顺序上下排列。每路显示放松度、压力值、心率、HRV、注意力和 Flow 的读数与数据时间，以及脑波波形和频段能量。连续订阅会更新对应指标和图表，`getLatest` 可读取一次。指标按算法原值显示，心率单位为 bpm。

展开「实时窗口详情」可查看各算法流最近一次实时窗口的时间、有效性及指标。勾选「同时接收无效窗口」可查看网关发送的原因。波形横轴为样本序号，纵轴显示算法幅度原值。频段图使用能量原值绘制刻度，缺失值以 `—` 表示。

「协议日志」左栏为耳机串口，右栏为头环蓝牙。每栏可独立复制或清空，最多保留最近 200 条。新版报文在 `data.source` 中标注 `headset`（耳机）或 `headband`（头环）。收到与连接所选设备不符的新版报文时，页面记录错误，不更新算法读数。

通过隔离专网独立联调时，打开 `index.html`，在对应设备的连接行输入批准的 WebSocket 地址。生产回环网关校验固定 Origin，应通过网关提供的本机 HTTP 页面访问。
